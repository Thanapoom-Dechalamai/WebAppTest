# บัญชีตัวอย่าง Lodgo ครบ 7 บทบาท

| บทบาท | หน้าที่ | อีเมล | รหัสผ่าน |
|---|---|---|---|
| Customer (เก็บเป็น `User`) | จองที่พัก เติมเครดิต | customer@lodgo.test | `123456` |
| HotelStaff · พนักงานโรงแรม (เก็บเป็น `HotelOwner`) | ยืนยัน/เช็กอิน/เช็กเอาต์ เฉพาะโรงแรมในทีม | hotelowner@lodgo.test | `LodgoDemo!2026` |
| Staff · Lodgo support | ค้นหาใบจอง ตามคำขอที่ค้าง | staff@lodgo.test | `123456` |
| Owner | ดูภาพรวมกิจการ | owner@lodgo.test | `123456` |
| Manager | จัดการทีม Customer/Staff และโปรโมชั่น | manager@lodgo.test | `123456` |
| Admin | ทุกอย่าง รวมถึงจัดทีมพนักงานโรงแรม | admin@lodgo.test | `123456` |
| AC | สถานะเงิน · สรุปยอดและโอนให้โรงแรม · กระทบยอด wallet | ac@lodgo.test | `123456` |

### พนักงานโรงแรมเพิ่มเติม 10 บัญชี (สร้างให้อัตโนมัติตอนเปิดเว็บ)
`hotelstaff01@lodgo.test` ถึง `hotelstaff10@lodgo.test` · รหัสผ่าน `LodgoDemo!2026` · บทบาท HotelStaff
ระบบแบ่งโรงแรมที่ยังไม่มีทีมให้ทั้ง 10 คนตามจังหวัด (1 คนดูแล 1 กลุ่มจังหวัด) ไม่แตะทีมที่ Admin ตั้งไว้แล้ว ดู/ปรับทีมได้ที่ Admin → จัดการทีมพนักงานโรงแรม
ถ้าลบบัญชีหรือเปลี่ยนบทบาทไปแล้ว ระบบไม่สร้างทับหรือเปลี่ยนกลับ

อีเมล .test เป็นบัญชีตัวอย่างสำหรับเข้าสู่ระบบ ไม่ใช่กล่องอีเมลจริง

## ลองเดิน flow ให้ครบใน 5 นาที
1. เข้า `customer@lodgo.test` → เลือกโรงแรมที่ **hotelowner** ดูแล (ค่าเริ่มต้นคือ th-stay-001) → จอง → เปิดหน้าใบจอง จะเห็นแถบความคืบหน้าและ "ขั้นต่อไป"
2. เปลี่ยนบัญชีเป็น `hotelowner@lodgo.test` → My Workspace → กล่อง "รอตรวจห้องว่างและยืนยัน" → กดยืนยัน
3. กลับไปบัญชีลูกค้า สถานะเปลี่ยนเป็น "ยืนยันการจองแล้ว"
4. เข้า `admin@lodgo.test` → พนักงานโรงแรม → จัดการทีมพนักงานโรงแรม เพื่อเพิ่ม/นำพนักงานออกจากทีมของแต่ละโรงแรม

## นำเข้าบัญชีตัวอย่าง

รันเว็บอย่างน้อยหนึ่งครั้งให้สร้างตาราง จากนั้นรันกับฐาน `lodgo_a9` ผ่าน MySQL Workbench หรือ `Open-MySQL.ps1`:
- `Database/seed-demo-roles.sql` — 6 บัญชีทีมงาน/ลูกค้า พร้อมรายการตัวอย่าง
- `Database/seed-hotel-owner.sql` — บัญชีพนักงานโรงแรมและเพิ่มเข้าทีม th-stay-001

ทั้งสองไฟล์นำเข้าซ้ำได้โดยไม่สร้างบัญชีซ้ำ
