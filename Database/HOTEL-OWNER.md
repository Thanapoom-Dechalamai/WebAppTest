# HotelStaff · พนักงานโรงแรม

ค่าบทบาทในฐานข้อมูลยังเป็น `HotelOwner` เพื่อให้บัญชีเดิมใช้ได้ต่อ หน้าเว็บแสดงเป็น "พนักงานโรงแรม"

## ทีมของโรงแรม
- ตาราง `hotel_assignments` เก็บ (HotelId, OwnerUserId) 1 โรงแรมมีพนักงานได้หลายคน และ 1 คนอยู่ได้หลายโรงแรม
- Admin จัดทีมที่หน้า พนักงานโรงแรม → จัดการทีมพนักงานโรงแรม (เพิ่ม / นำออก)
- พนักงานเห็นและจัดการได้ **เฉพาะการจองของโรงแรมที่ตนอยู่ในทีม** ทั้งในหน้าเว็บและในการตรวจสิทธิ์ฝั่งเซิร์ฟเวอร์ผ่าน `HotelDeskService` และ `IActorDirectory`
- บัญชีพนักงานที่ยังไม่อยู่ในทีมใด จะเห็นหน้าว่างพร้อมข้อความให้ติดต่อ Admin
- ฐานข้อมูลเดิมที่ใช้ HotelId เป็น key อย่างเดียว ระบบปรับ key ให้อัตโนมัติตอนเปิดเว็บ ข้อมูลเดิมไม่หาย

## งานของพนักงานโรงแรม
หน้าแรกแสดงกล่อง "ต้องทำตอนนี้": รอยืนยัน · เข้าพักวันนี้ · กำลังเข้าพัก
- ห้องว่าง → **ยืนยัน** (บันทึกยอดรับของโรงแรม)
- ห้องไม่ว่าง → **ยกเลิก** พร้อมเหตุผล (คืนเครดิตและคืนสิทธิ์โค้ดให้ลูกค้า)
- วันเข้าพัก → **เช็กอิน** → **เช็กเอาต์**
- ลูกค้าไม่มา → **ลูกค้าไม่มา** (ปิดรายการ ไม่คืนเครดิต)

ยอดรับเป็นของโรงแรม พนักงานทุกคนในทีมเห็นตัวเลขเดียวกัน คอลัมน์ OwnerUserId ใน `hotel_owner_entries` คือคนที่บันทึก
พนักงานโรงแรมจองที่พักหรือเติมเครดิตไม่ได้ เพื่อไม่ให้จองแล้วยืนยันรายการของตัวเอง

ระบบไม่ได้ตัดสต็อกห้องอัตโนมัติ พนักงานตรวจห้องว่างก่อนกดยืนยัน
